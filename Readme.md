# Discord Landing Page Clone

A responsive landing page inspired by Discord. This project helped me learn how the page is structured and how its layout and styling are written using HTML and Tailwind CSS.

## About the Project

This is a tutorial-based project, not a website I designed and built from scratch. I followed along with the project and learned how the code works as I wrote it. It was a useful way to practice reading, understanding, and writing frontend code.

The page includes a navigation bar, a hero section, feature sections, download prompts, and a footer. Its layout adapts to different screen sizes.

## Built With

- HTML
- Tailwind CSS
- Vite

## Run Locally

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder:

   ```bash
   cd discordCLone
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open the local URL shown in your terminal.
